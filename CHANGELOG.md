# Changelog

## [0.6.0] — 2026-05-21

### UI / Визуальный стиль

- **Liquid glass** — единый стиль для всплывающих элементов: `backdrop-filter: blur + saturate`, `color-mix` фон, полупрозрачная белая рамка. Применено к:
  - Дропдауну сообщений (`GramotaMessage`)
  - Пикеру эмодзи (`EmojiPicker`)
  - Селектору устройств в войс-баре (`ActiveVoiceBar`)
- **EmojiPicker** — новый дизайн: компактные иконки-вкладки с `opacity` вместо подчёркивания, эффект `scale` при наведении на смайлик

### Голосовой бар (`ActiveVoiceBar`)

- Редизайн в стиле Google Meet
- Селектор микрофона / колонок через **Portal** с `position: fixed` — больше не обрезается `overflow: hidden`
- Дропдаун разбит на секции «Микрофон» и «Динамик» с индикацией активного устройства (`Check`)

### Настройки (`Settings`)

- Кнопка «Сбросить» горячие клавиши перенесена в правый угол заголовка карточки
- Иконка `RefreshCw` с анимацией вращения при наведении
- Убрана иконка `Keyboard` из заголовка — вместо неё `Mic` в строке привязки клавиши

### Настройки сервера (`ServerSettingsPage`)

- Страница настроек сервера переведена в **модальное окно** (аналог настроек профиля) — открывается без навигации
- Добавлен `ServerSettingsModalContext` + рендерер в `AppLayout`
- Кнопка «⚙» в `PalataList` теперь открывает модалку вместо роутинга

### Управление ролями (`RolesManager`)

- Убраны вложенные Portal-модалки (рендерились **за** модальным окном настроек)
- Создание и редактирование роли теперь работают как **экраны внутри модалки** с кнопкой «← Назад к ролям»
